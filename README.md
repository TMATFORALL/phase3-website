# TMAT โปรเจคไฟฟ้า

เว็บไซต์ของสตูดิโอที่ปรึกษาและสอนทำโปรเจคไฟฟ้า ระดับ ปวช. ปวส. และมินิโปรเจคปริญญาตรี

เป็นไฟล์ HTML ล้วน ไม่ต้อง build เปิดในเบราว์เซอร์ได้ทันที หรือเผยแพร่ผ่าน GitHub Pages

- `index.html` หน้าแรก (บริการ หมวดโปรเจค แพ็กเกจ ผลงาน ติดต่อ)
- `learn.html` คลังความรู้ (ขั้นตอนทำโปรเจค โครงสร้างเล่ม สูตร เครื่องคำนวณโซลาร์ คำถามกรรมการ เช็กลิสต์ก่อนสอบ)

## ก่อนใช้งานจริง ต้องแก้

- ชื่อร้าน ตัวเลขสถิติ ราคา และรีวิว (ตอนนี้เป็นข้อมูลสมมติ)
- LINE ID ในส่วน `#contact`
- ใส่รูปงานจริงแทนช่อง "ใส่รูปงานจริง" ในส่วนผลงาน
- เปลี่ยนลิงก์ปุ่ม LINE (`href="#contact"`) เป็นลิงก์ LINE OA จริง เช่น `https://line.me/R/ti/p/@yourid`

## แก้สีและฟอนต์

สีและฟอนต์ทั้งหมดอยู่ในบล็อก `:root` ด้านบนของ `<style>`

- `--copper` สีหลัก
- `--bg` สีพื้นหลัง
- `--f-display` / `--f-body` ฟอนต์ (ตอนนี้ใช้ Anuphan จาก Google Fonts)
