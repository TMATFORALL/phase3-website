# เฟสสาม โปรเจคไฟฟ้า

หน้าเว็บตัวอย่าง (mockup) ของสตูดิโอที่ปรึกษาและสอนทำโปรเจคไฟฟ้า ระดับ ปวช. ปวส. และมินิโปรเจคปริญญาตรี

เป็นไฟล์ HTML ไฟล์เดียว (`index.html`) ไม่ต้อง build เปิดในเบราว์เซอร์ได้ทันที หรือเผยแพร่ผ่าน GitHub Pages

## ก่อนใช้งานจริง ต้องแก้

- ชื่อร้าน ตัวเลขสถิติ ราคา และรีวิว (ตอนนี้เป็นข้อมูลสมมติ)
- LINE ID และเบอร์โทร ในส่วน `#contact`
- ใส่รูปงานจริงแทนช่อง "ใส่รูปงานจริง" ในส่วนผลงาน
- ลบแถบ "หน้าตัวอย่าง (mockup)" ด้านบนสุด
- เปลี่ยนลิงก์ปุ่ม LINE (`href="#contact"`) เป็นลิงก์ LINE OA จริง เช่น `https://line.me/R/ti/p/@yourid`

## แก้สีและฟอนต์

สีและฟอนต์ทั้งหมดอยู่ในบล็อก `:root` ด้านบนของ `<style>`

- `--copper` สีหลัก
- `--bg` สีพื้นหลัง
- `--f-display` / `--f-body` ฟอนต์ (ตอนนี้ใช้ Anuphan จาก Google Fonts)
